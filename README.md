# 🍳 今天吃什么 · 转盘点菜

把爱吃的菜（照片 + 名称 + 类型）录进来，转盘帮你拿主意，告别每天"不知道吃什么"。

## 功能

- 🎡 **转盘点菜**：点「开始转」，转盘减速停下弹出结果大图
- 📖 **五类菜单**：主食 / 甜品 / 汤 / 小炒 / 大菜，可按分类筛选转盘
- 📷 **录入菜品**：菜名 + 照片 + 类型，照片自动压缩到 800px 存本地
- ✏️ **增删改**：菜单管理里可编辑、删除；没有照片就用彩色扇形 + 菜名
- 📱 **PWA**：可「添加到主屏幕」当独立 App 用，支持离线缓存

## 数据

菜品数据（含照片）全部存在**你自己的浏览器本地 IndexedDB**，不上传任何服务器。

> ⚠️ 数据不跨设备同步：电脑上录的与手机 App 里的是两份独立数据。

## 部署

纯静态站点，托管于 GitHub Pages。
